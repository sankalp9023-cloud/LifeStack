# Shared Components

This directory houses reusable, cross-cutting UI components that do not belong to a single feature domain:

- **`common/`**: Universal visual elements (badges, loaders, alert banners, avatars).
- **`navigation/`**: Application navigation (compact top toolbar, breadcrumbs, nav pills).
- **`panels/`**: Translucent glass containers, orbital pods, organic curved shells.
- **`ui/`**: Core input controls (buttons, toggles, text inputs, modal dialogs, tooltips).
